# VirtualDev Studio — API Documentation

**Version:** 0.1.0 · **Base URL:** `http://localhost:8000` · **API prefix:** `/api/v1`

This reference documents every route **actually implemented** in
`backend/app/api/`. It was generated by reading the router source files and the
Pydantic schemas, and verified against the running test suite.

- `backend/app/api/auth.py` — `POST /auth/register`, `POST /auth/login`
- `backend/app/api/projects.py` — project CRUD + stages
- `backend/app/api/entities.py` — project sub-resources (requirements, research, architecture, tasks, approvals, documents, diagrams, agents)
- `backend/app/api/orchestrate.py` — orchestration start/continue
- `backend/app/api/websocket.py` — real-time channel
- `backend/app/main.py` — root + health

Interactive docs are served by FastAPI at **`/docs`** (Swagger) and **`/redoc`**.

---

## 1. Conventions

### Authentication

Most endpoints require a JWT **access token**:

```
Authorization: Bearer <access_token>
```

Tokens are issued by `POST /api/v1/auth/login` (`type=access`, default lifetime
**30 minutes**, configurable via `ACCESS_TOKEN_EXPIRE_MINUTES`) and refreshed by
`POST /api/v1/auth/login` again (`type=refresh`, default lifetime **7 days**).

- Missing or malformed credentials → `401` with `detail`:
  - no header: `"Not authenticated"`
  - invalid token: `"Invalid authentication credentials"`

### Ownership model

Every project-scoped resource verifies that the authenticated user **owns** the
project (`Project.owner_id == current_user.id`). A project that is missing or owned
by another user returns `404 {"detail": "Project not found"}`.

### Error shape

Non-2xx responses follow FastAPI's default error body:

```json
{ "detail": "<human-readable error>" }
```

### Rate limiting

`POST /auth/register` and `POST /auth/login` are rate-limited
(`RateLimiter`, default 100 requests / 60 s per client IP, in-memory). Exceeding the
limit returns `429`:

```json
{ "detail": "Rate limit exceeded. Max 100 requests per 60 seconds." }
```

## 3. Authentication — `/api/v1/auth`

### `POST /api/v1/auth/register`

Register a new user. Creates an account with a bcrypt-hashed password.

**Request body** (`UserCreate`):

| Field | Type | Notes |
|---|---|---|
| `email` | string | required |
| `full_name` | string | required |
| `password` | string | required |

**Example request:**

```json
{
  "email": "ada@example.com",
  "full_name": "Ada Lovelace",
  "password": "str0ng-password!"
}
```

**Example response (201)** — `UserResponse` (`/api/v1/auth/register`):

```json
{
  "id": "3f7c6801-8c1e-4f3a-9d2b-0e1f2a3b4c5d",
  "email": "ada@example.com",
  "full_name": "Ada Lovelace",
  "role": "user",
  "is_active": true,
  "created_at": "2026-09-15T12:00:00Z"
}
```

No password fields are ever returned.

**Error responses:**

| Code | Body |
|---|---|
| `400` | `{"detail": "Email already registered"}` |
| `429` | rate limit exceeded |

**Tested by:** `test_register_success`, `test_register_duplicate_email`.

### `POST /api/v1/auth/login`

Authenticate and receive JWT tokens.

**Request body** (`UserLogin`):

| Field | Type | Notes |
|---|---|---|
| `email` | string | required |
| `password` | string | required |

**Example request:**

```json
{ "email": "ada@example.com", "password": "str0ng-password!" }
```

**Example response (200)** — `TokenResponse`:

```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer"
}
```

**Error responses:**

| Code | Body |
|---|---|
| `401` | `{"detail": "Invalid credentials"}` (uniform for wrong password and unknown email) |
| `429` | rate limit exceeded |

**Tested by:** `test_login_success`, `test_login_wrong_password`, `test_login_nonexistent_user`.

## 6. Orchestration — `/api/v1/projects/{project_id}/orchestrate`

### `POST /projects/{project_id}/orchestrate/start`

Run the AI workflow over the project. Executes the 11-stage
`WORKFLOW_STAGES` pipeline; non-gated stages run immediately and approval-gated
stages (`architecture`, `development`, `security_review`) create a pending approval
and a `pending_approval` task, then pause.

**Example response (200):**

```json
{
  "status": "started",
  "project_id": "3f7c6801-8c1e-4f3a-9d2b-0e1f2a3b4c5d",
  "current_stage": "documentation"
}
```

After a successful start the project `status` becomes `"in_progress"`.

**Errors:** `404 {"detail": "Project not found"}`.

**Tested by:** `test_start_orchestration`, `test_start_orchestration_not_found`.

### `POST /projects/{project_id}/orchestrate/continue`

Resume the workflow. Re-processes every stage that is `pending`, `in_progress`,
`failed`, or `waiting_approval`:

- already-decided `approved` approval → stage completed (+ architecture output re-materialized)
- already-decided `rejected`/`modified` approval → stage marked failed
- still-pending approval → skipped (kept waiting)

**Example response (200):**

```json
{
  "status": "continued",
  "project_id": "3f7c6801-8c1e-4f3a-9d2b-0e1f2a3b4c5d",
  "current_stage": "architecture"
}
```

**Errors:** `404 {"detail": "Project not found"}`.

**Tested by:** `test_continue_orchestration`, `test_continue_orchestration_project_not_found`.

> **Note:** the continue handler iterates `next_stages.scalars().all()` (a list); an
> earlier revision applied `scalar_one_or_none()` and surfaced `MultipleResultsFound`
> + a `None.value` crash in `_execute_stage`. These defects were fixed; both continue
> tests pass. See `docs/testing/testing-report.md`.

## 7. WebSocket — `/ws/projects/{project_id}`

Live channel for a project. Public URL (no authentication or ownership check — see
security finding `F-WS-01`).

**Handshake:** `ws://localhost:8000/ws/projects/<project_id>`

**Protocol:** JSON text frames. The server echoes pings:

Client → `{"type": "ping"}` · Server → `{"type": "pong"}`

Disconnects are handled (`WebSocketDisconnect`); malformed JSON is not currently
caught (finding `F-WS-02`).

The `ConnectionManager` (`backend/app/api/websocket.py`) keeps per-project
connection lists and a `broadcast()` method that the orchestrator can later use to
push live stage updates (`orchestrator.websocket_manager` is currently unused).

## 8. Status Codes Summary

| Code | Meaning | Where |
|---|---|---|
| `200` | OK | all GET + PATCH + orchestration + decide + login |
| `201` | Created | `POST /auth/register`, `POST /projects` |
| `400` | Bad request | duplicate email, already-decided approval |
| `401` | Unauthenticated | missing/invalid bearer token, bad login |
| `404` | Not found | foreign/missing project, missing approval |
| `429` | Too many requests | auth endpoints rate limit |
| `5xx` | Server error | unexpected errors (FastAPI default) |
